# Audit v2 Index

This folder contains the second full audit of the Apex Trading Bot project.

Files included:

- `EXECUTIVE_SUMMARY.md` — high-level status, critical findings, and risk overview.
- `FINDINGS.md` — detailed findings per subsystem with exact file references.
- `SOLUTION_GUIDE.md` — remediation plan, ordered fixes, and guidance for junior developers.

Scope:

- Backend trading orchestration and risk pipeline
- Frontend settings and API integration
- Metrics/dashboard data sources and placeholder behavior
- Copy trading data path
- Configuration and runtime assumptions

This audit was performed independently of `audit/v1` and reflects the current code state.
