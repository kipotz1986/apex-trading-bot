# Audit v3 Index

This folder contains the third full audit of the Apex Trading Bot project.

Files included:

- `EXECUTIVE_SUMMARY.md` — high-level status and current risk assessment.
- `FINDINGS.md` — detailed findings per subsystem with file references.
- `SOLUTION_GUIDE.md` — concrete remediation steps for current issues.

Scope:

- Backend orchestration and risk settings flow
- Frontend settings integration and command wiring
- Metrics and copy trading service behavior
- Current execution code paths and persistence

This audit is performed independently from `audit/v1` and `audit/v2`.
